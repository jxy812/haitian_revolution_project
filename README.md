# Haiti — Freedom at a Price

An interactive historical exhibition by Jessie Xie.

Open index.html directly or use VS Code Live Server. No build or installation is required. Keep the assets folder and scripts together.

## Files

- index.html: historical exhibit, source annotations, and citations.
- data.js: shared event, group, location, and profile records.
- script.js: timeline, map, group, profile, keyboard, and navigation behavior.
- style.css: responsive design and local font definitions.
- assets/: local fonts, historical print, and Atlantic locator map.
- Works Cited.pdf: separate MLA document.
- works-cited.html: printable HTML bibliography.
- Submission Review.md: rubric review, remaining submission decisions, and reflection starting draft.

## Evidence and image revision

The expanded exhibit includes a close reading of the 1801 constitution, named restitution proposals, a scoped debt-service statistic, and an explicit outcome assessment. See Organizer Evidence Review.md for the full coverage audit.

All four figures have sourced historical portraits with dates and provenance. The 1780 Des Longchamps map is available as an expandable archival comparison; the original interactive map is retained. Complete media references are in Works Cited. The four new portraits are not subject to the older print’s sepia styling.
